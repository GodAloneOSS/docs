# Getting Started (For Users)

## What is GodAlone Open Source?

GodAlone Open Source is a collection of free, freely-available websites,
apps, calculators, and Quran resources, built and shared for the sake of
Allah. Everything here is free to use — no login required unless a
specific tool needs one for a good reason, and never any hidden cost.

## What projects are available?

[Keep this list in sync with the landing page — see the org's

- **Quran** — Quran Web App, search tools, reading tools, verse tools,
  audio resources, translations
- **Education** — Quran Quiz (with Text-to-Speech), Kids Quran Coloring
  Book, interactive learning tools
- **Calculators** — Zakat, Salat Time, Ramadan, 19-Calculator, Inheritance
  (coming soon)
- **Websites** — godalone.in, kadavulmattum.org (Tamil), ekkhuda.org

## How can I use them?

Most tools are web-based — just visit the site or app link, no
installation needed. [Add specifics once live links exist.]

## How can I download / self-host a project?

Every project's GitHub page has an "Installation" section in its README
with copy-paste instructions. If you get stuck, see
[How to Report a Problem](#how-can-i-report-a-problem) below — we're happy
to help.

## How can I report a problem?

1. Find the relevant project on [github.com/GodAlone](https://github.com/GodAlone).
2. Click the "Issues" tab, then "New Issue".
3. Pick "Bug Report" and fill in what happened.

No GitHub account? You can also reach us at [contact email/method to be
filled in].

## How can I suggest an improvement?

Same as reporting a problem, but pick "Feature Request" instead of "Bug
Report" — we'd genuinely love to hear your ideas.
