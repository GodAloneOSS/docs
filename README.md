# GodAlone Open Source — Documentation

This repo holds the central documentation for the whole GodAlone Open
Source ecosystem, split into three entry points:

- **[For Users](users/getting-started.md)** — what this is, what projects
  exist, how to use them, how to report a problem. No technical background
  assumed.
- **[For Developers](developers/architecture.md)** — architecture overview,
  local dev setup per project type, how the shared foundations
  (`quran-data`, `i18n-strings`, `design-system`) are consumed, testing and
  release process.
- **[For Contributors](contributors/how-to-contribute.md)** — the
  step-by-step fork → PR workflow, and where to find a good first issue.

This repo can be published as a static site via GitHub Pages, or browsed
directly on GitHub.
